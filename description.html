Course Description

Theme

Topics Course in Geometric Modeling: Point Cloud Segmentation

Study of mathematical models of 3D scenes composed of geometric
objects represented by point sets with visual attributes.
Fundamental principles and advanced machine learning techniques for
analysis and processing of this data representation.
Applications to semantic instance segmentation of oil & gas plants
in the context of Centro Pi - RADIX project.

Main topics: Machine Learning Fundamentals; Geometric Deep Learning; Convolution
Neural Network Architectures; Localization and Detection;
Segmentation; Geometric Models and Representations; Points Nets; Deep
Meshes; Transformers and Attention; Self-Supervision;  Review of
Selected Papers.
